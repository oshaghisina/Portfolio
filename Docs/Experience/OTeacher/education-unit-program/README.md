## Process

- Formed a supervisory team from active, experienced teachers.
- Interviewed all teachers and categorized them.
- Designed standards, educational processes and interview criteria.
- Ran specialized classes to upskill teachers.
- Stood up a formal Education unit to raise teaching satisfaction and quality.

## Solution
