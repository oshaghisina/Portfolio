# Matchmaking Redesign

> One-line summary: two-sided research into teacher and student pain points, surfacing match quality as the core problem behind OTeacher's "matchmaking" roadmap item.

## Context

OTeacher's own brand-positioning analysis (see
[product-roadmap-and-strategy](../product-roadmap-and-strategy/README.md)) names the goal of
moving from "one option among several" to the "first choice" for online language learning.
Matching a student with the right teacher is one of the levers identified toward that goal.

## Problem

Research surfaced pain points on both sides of the marketplace:

- **Teachers** (persona headline: "students don't pay!") — need better tools/facilities for
  teaching; want more income.
- **Students** (persona headline: "what happened to our class?!") — past bad learning
  experiences; **finding a well-matched, quality teacher**; an unclear learning path; weak
  in-site class and communication tooling.

The bolded student pain point is the direct root of the "matchmaking" initiative named on the
roadmap.
