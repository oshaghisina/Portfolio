# Design-System — inspiration items

Patterns, tokens and components worth borrowing or adapting for Sina's site, one file per item
(`DS-NN-<slug>.md`, from `_template.md`). An item is a **cross-benchmark pattern**: its
`sources[]` lists every benchmark where it was seen and grows as more sites are scanned. Items
start as `candidate`s; they become `adopted` or `rejected` through [Synthesis](../Benchmarks/Synthesis.md)
and [Decisions](../Decisions.md), and their `target` says where each lands in the codebase
(feeds [Content-Model.md](../Content-Model.md) §10). Decided in D-013 / D-014.

## What lives here

| Path | What | Committed |
|---|---|---|
| `DS-NN-<slug>.md` | One item: identity, take, priority, adoption, sources, target, RTL / Persian notes, measured values, evidence list, open questions | yes |
| `tokens/<benchmark>.tokens.json` | Measured design tokens of a source site, W3C DTCG JSON (`$value` / `$type` / `$description` / `$extensions`); provenance under `$extensions["com.sinaoshaghi.docs"]` | yes |
| `sources/<benchmark>.capture.json` | Capture manifest: what `docs:ds-capture` crops and measures per item on that site | yes |
| `assets/<benchmark>/` | Element crops @2x, states, viewport shots, frame sequences, short videos, `DS-NN.json` measurements, raw stylesheet snapshot | **no** — local-only (D-008 rule) |
| `tokens/sina.tokens.json` | **House tokens** — Sina's own values, one per decision, each with `derivedFrom: "pleurat-com:<path>"` and `item: "DS-NN"`; `color.light.*` / `color.dark.*` sibling groups, `font.fa.*` Persian overrides, shadcn slots as DTCG aliases (`"{color.light.paper}"`). The only input of `pnpm tokens:build` | yes |
| `../../src/app/(frontend)/theme.css`, `../../src/cssVariables.js` | **Generated** by `pnpm tokens:build` — never edited; `pnpm docs:check` fails on drift (D-018) | yes |

## Legend

- **Category** — `foundation` (tokens) · `type-device` · `layout` · `component` · `motion` · `signature` (metaphor-level pieces that must be re-imagined, never copied)
- **Take** — `borrow` (structure transfers as-is) · `adapt` (needs Sina's own values, metaphor or a Persian path) · `avoid` (kept as a counter-example)
- **Priority** — `P1` first sprint · `P2` next · `P3` later
- **Adoption** — `candidate` → `adopted` | `rejected` | `superseded` (by another item)
- **Status** — `draft` → `review` → `ready`; `ready` requires a decided adoption, a filled target and no `❓`

## Workflow

1. `pnpm docs:ds new "<title>" --category … --take …` (or `pnpm docs:ds seed <items.json>` for a batch) — scaffolds the file and re-indexes.
2. Add the item to `sources/<benchmark>.capture.json` (route, anchors, capture kinds, probes).
3. `pnpm docs:ds-capture <benchmark> --item DS-NN` — writes crops, frames, `DS-NN.json`, tokens and the item's `evidence[]`.
4. Write **Measured / Anatomy** from `assets/<benchmark>/DS-NN.json`, then **For Sina** (take · RTL · Persian) and **Target mapping**.
5. `pnpm docs:check` before committing. Stage `assets/` never — it is gitignored.
6. To **adopt** an item: add Sina's values to `tokens/sina.tokens.json`, run `pnpm tokens:build`,
   build the target, set `adoption: adopted`, point `target` at the real file and add an
   *Implemented* note under Target mapping. Everything adopted is rendered live on `/design`
   (`?lang=fa` for the Persian preview; the theme toggle is in the footer).

## Naming

- **Roles, then slots.** Colour tokens are roles (`paper · panel · ink · ink-2 · ink-3 · line ·
  line-soft · brand · brand-foreground · ring · danger · success · warning`), emitted as `--paper`
  … and used as `bg-paper`, `text-ink-2`, `border-line`. The shadcn slots the template UI expects
  (`--background`, `--card`, `--muted-foreground` …) are aliases inside each theme group.
- **Type roles, not steps:** `font.size.{display,h1,h2,h3,lede,body,small,caption,eyebrow,button,num}`
  → `text-<role>`, each with `font.leading.<role>` / `font.tracking.<role>` companions.
- **Persian overrides** mirror the base path with a `fa` segment: `font.fa.leading.body` → the
  same `--leading-body` variable inside `:lang(fa)`.
- **Mapping to Tailwind v4** lives in `scripts/tokens/lib/emit.ts` (`cssName`): `space.*` →
  `--spacing-*`, `size.control.*` → `--size-control-*`, `size.container` → `--container-page`,
  `motion.ease.*` → `--ease-*`, `motion.duration.*` → `--duration-*`, `radius.*` → `--radius-*`.
